A working glossary for the [[index|Valley of Grace High School Decision Tool]]. Every acronym, institution, and specialist term the tool uses is defined here in one place, with cross-links back into the variables, options, and research pages that put each term to work.

The entries are grouped by function below. Follow any wikilink to read the full entry.

## How to use it

If a term in the Decision Tool is unfamiliar, search this folder or open the entry directly (the file name is the term, in kebab-case). Every entry ends with a *See also* block that links to related glossary entries and to the corresponding pages in the tool.

Evidence tags ([[ic|IC]], [[ms|MS]], [[tbv|TBV]]) are the first place to start if you want to weigh the claims made anywhere on the site.
